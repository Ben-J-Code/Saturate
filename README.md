# Saturate

#### Give your browser a vibrancy boost with Saturate! Saturate individual or all websites.



##### Compatibility

* Google Chrome
* Microsoft Edge
* Brave



*Other chromium based browsers may also be compatible, but have not been officially tested.*



##### How to install

1. Download all the files into a folder on your computer. Make sure the folder is empty first and somewhere you'll remember.
2. Navigate to your extensions tab on your browser (often top right or listed on the top right dropdown) and click "Manage extensions".
3. You should see a toggle called 'Developer mode', this will need to be turned on if not already.
4. A set of 'Developer options' should show up. You should click on 'Load unpacked'.
5. Navigate though your files to where you downloaded Saturate, select the folder and click 'Select Folder'.
6. The extension should now be installed.



##### How to use

1. Saturate should now show up at the top right in your extensions tab. Click it to open it up.
2. One thing to note about Saturate is it only works on webpages, not including browser pages (such as browser settings). If the settings appear as 'Loading...' for an extended period of time, this may be why.
3. Once open on a compatible page, you will be shown 2 sections. One being Default Setting, and one being This Website's Setting.
4. Default Setting just means the saturation that you want applied to all webpages. This can also be on or off by default.
5. This Website's Setting means a saturation boost / decrease specific for that webpage. To enable, make sure the tick box is set to 'Custom Setting' and then choose the saturation level.
6. User preferences are saved to your browser.
